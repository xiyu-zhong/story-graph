# 故事图谱：视觉素材规范 v1.0

> 状态：当前素材设计与交付基线，配套 [产品设计规范 v1.0](产品设计规范-v1.0.md)。
> 适用：项目背景、作品封面、故事插图、人物头像、地图底图，以及由这些素材派生的分享图片。
> 当前已有四张原创 SVG 概念封面，实际资产见 [素材记录](../public/art/manifest.json)。尚未调用付费图像 API；素材生成方式与适用边界必须如实标明。

## 1. 视觉原则

根据最新开发方向，应用外观采用“精致的科幻叙事终端 + 作品各自的叙事视觉”：深色空间、星轨、低亮度网格、金属细线与克制的强调色。首页可用 Three.js 实时三维轨道与星点；图谱与正文仍以清晰为先。不同作品共享尺寸、排版、安全区与交互规则，但不把科幻界面风格误写进原作世界设定。

- 封面、作品入口、章节插图负责故事氛围。
- 图谱画布、正文与控制区优先清晰，背景不得抢过人物节点、连线与文字。
- 不用一张大图覆盖整个应用；内容区与图谱区各有低干扰背景或不透明容器。
- 同一作品的封面、场景图、人物形象共享一份美术设定。
- 故事事实与视觉想象分开；生成插图不得用作事件、关系或地理依据。
- 不预设必须依赖生成式模型，SVG、程序绘制、授权素材和人工插画均可按同一规范交付。

首轮画风默认：简洁构图、适度细节、明确焦点、克制色彩的叙事插画。古典、水墨、写实、科幻等是作品主题选择，不设为全站唯一画风。

## 2. 素材类型与尺寸

以下尺寸是交付目标，不是对任意图像模型原生输出能力的假设。生成时选择服务商支持的合适尺寸，再通过审查后的裁切、扩图或重构图得到交付文件，不拉伸变形。

| 类型 | 默认比例 | 制作母版目标 | 常用交付 | 要求 |
|---|---|---|---|---|
| 作品封面 | 2:3 | 1200×1800 或更高 | 400×600、800×1200 WebP | 插画底图与书名/片名文字分离 |
| 桌面作品背景 | 16:9 | 2560×1440 | 1280×720、1920×1080 WebP | 标题区低细节，保留裁切余地 |
| 手机作品背景 | 4:5 | 1200×1500 | 800×1000 WebP | 独立检查构图，不直接截断横图主体 |
| 章节/场景插图 | 16:9 | 1600×900 或更高 | 960×540、1600×900 WebP | 与当前内容和版本一致 |
| 人物头像 | 1:1 | 768×768 或更高 | 128×128、256×256 WebP/PNG | 方形与圆形裁切都可辨识 |
| 图谱画布背景 | 自适应或平铺 | 优先 SVG/CSS；纹理可用 512/1024 方图 | SVG 或小型 WebP | 极低干扰、可关闭，不能含真实节点与标签 |
| 地图底图 | 跟随空间范围 | 长边默认至少 2048，按缩放需求调整 | 底图+独立标注/路线数据 | 不为比例统一而破坏空间关系 |
| 分享卡 | 约 1.91:1 | 1200×630 | JPG/PNG/WebP，依平台支持 | 用插画与文字后期合成，服从进度范围 |

复杂地图允许单独定义尺寸和加载策略，不把大图无条件预加载。母版尺寸不等于页面必须下载的尺寸。

## 3. 图片与文字、数据必须分层

### 3.1 封面与背景

封面原始插画默认不含书名、片名、作者、Logo 和界面文字；使用前端排版或确定性的图片合成加入文字，以保证中文准确、字号一致并适应长标题。

- 封面主要视觉应保留在中央约 80% 范围，四边预留约 10% 的裁切余地。
- 默认封面下方约 25% 为较低细节的标题区；具体作品可改为上方，但整套保持一致。
- 桌面横幅默认左侧约 40% 为文字区，主体放右侧；镜像构图作为独立变体。
- 手机背景需单独检查标题、人物脸部和关键物件，不以自动居中裁切代替审查。
- 必须保留不带文字的母版。分享卡等最终文件可以合成文字，但不得覆盖母版。

### 3.2 地图

地图分为底图、地点标注、路线、交互高亮四层。

生成式模型可提供山水纹理、环境氛围或参考草图，但不得直接决定城市相对位置、房间连接和路线。先有经过整理的空间结构，再绘制底图并校验。

地名、人物标记、章节编号与路线用可编辑图层表达，不能只存在于一张不可修改的生成图片里。

底图更换、裁切或改变尺寸时必须检查坐标对应关系。底图与标注使用明确的版本和坐标约定，不能移动地标后继续沿用旧标注。

### 3.3 图谱背景

可包含微弱纸感、渐变、网格或抽象纹理，不得包含看似真实关系的装饰连线，避免用户把背景看成数据。

复杂插画只用于作品入口或画布边缘；默认图谱工作区不放高细节场景图。支持纯色回退和关闭装饰背景。

## 4. 可读性与主题适配

- 正文文字对最终合成背景的对比度目标至少为 4.5:1；大字号文字至少为 3:1；关键交互边界和图形信息以 3:1 为目标。
- 必须检查实际图片与遮罩合成后的结果，不只检查设计色值。
- 必要时使用不透明或半透明文字容器，不能仅依赖文字阴影。
- 人物关系类型不只靠颜色表达，还需标签、线型或方向。
- 浅色/深色主题可共用插画母版，但遮罩与色调应分别检查。
- 装饰性背景提供空替代文字；承载内容的图片提供简洁说明，并遵守剧透边界。

## 5. 每部作品的美术设定模板

```text
作品与版本：
媒介类型：
素材适用模式：通用无剧透 / 指定阶段 / 全貌或读后
主题与情绪：
时代、环境与世界设定：
主色 / 辅色 / 强调色：
材质、光照与细节密度：
构图规则与标题留白：
允许使用的象征元素：
人物外观设定（仅已知信息）：
地点外观设定及事实/想象边界：
需要保持一致的参考素材：
禁止出现的元素、未来信息和时代错置：
素材来源与参考图使用权：
```

首轮每个作品默认选择一个主画风，不把完全不同的画风混用为同一批正式素材。人物一致性通过设定、参考图与人工筛选维护，不承诺模型能自动保证。

固定随机种子并不等于跨模型或跨版本画面一致；工具支持时可记录种子，但不能用它替代参考设定和审核。

## 6. 生成任务模板

```text
【任务】用途、对象、作品版本、资产类型
【内容】必须出现的主体、环境、动作与情绪
【依据】允许引用的已知内容，明确哪些是视觉想象
【风格】使用作品美术设定，不临时另造一套风格
【构图】目标比例、主体位置、裁切安全区、文字留白
【限制】不含界面文字/Logo；不得出现的剧情、身份、物件
【参考】有权使用的设定图、构图图或已有素材
【输出】服务支持的生成尺寸、目标交付尺寸、是否需要透明
【审核】剧情、身份、空间、裁切、文字、安全范围及素材来源
```

透明输出、局部编辑、多图参考等能力按实际模型支持选择，不作为所有服务的默认保证。提示词中的文字留白指低细节构图区，并不保证模型精确执行，必须检查成图。

### 示例：无剧透作品封面

以下是模板，不对应某一真实作品：

```text
为原创作品《{作品名}》制作不含文字的 2:3 竖版封面插画。
主题与情绪：{主题、情绪}。
主体：{已经公开且不会泄露后续情节的元素}。
风格、色彩与光照：{作品美术设定}。
主要主体位于中央安全区，下方约四分之一保持低细节供后期排标题。
禁止：书名、作者名、Logo、未来揭示的身份、结局场景、未经确认的角色外观。
交付时保留无字母版；后期由排版层加入准确标题。
```

## 7. 剧透与真实性

- 全站和作品入口默认使用无剧透装饰素材；不用终局人物阵容、身份揭晓、死亡或最终地点作为默认背景。
- 阶段性插图、头像和地图若包含进度信息，必须绑定作品版本和揭示位置。
- 图片标题、说明、替代文字及分享预览服从同一进度边界。
- 生成的角色形象是美术表达，不默认等于原作确认的长相。
- 生成的影视插画不得标成官方海报、真实剧照或演员照片；必须保留素材性质说明。
- 涉及真实人物形象、官方标识或参考素材时，另行检查授权、呈现方式及适用规则。
- 未经核实的建筑布局和地图必须标为示意；无充分依据时不给精确结论。

## 8. 文件与元数据

实际应用目录尚未确定，本规范约定逻辑分层，不要求现在创建所有文件夹：

```text
视觉源文件：无字母版、设计源文件、参考与制作记录
发布文件：经过审校和压缩的页面素材
元数据：来源、对象绑定、版本、尺寸、揭示范围、审核记录
```

命名模板：

```text
{work-id}__{version-id}__{asset-type}__{variant}__r{revision}.{ext}
```

`work-id` 与 `version-id` 使用项目实际标识。全站通用装饰素材以独立的项目级作用域管理，不伪装成某一作品版本。

每项素材必须记录：

- 素材标识、作用域、所属作品/版本、关联单元/人物/地点。
- 类型、变体、修订号、母版与发布文件位置、宽高、格式。
- 来源类型：程序绘制、人工设计、授权素材、生成式制作等。
- 创作者/服务商、模型及其可用版本信息、提示词、参考来源；不适用项明确为空。
- 使用权说明、限制和待核实事项；“由 AI 生成”不等于自动具有无限使用权。
- 适用模式、信息揭示位置、替代文字。
- 内容审查、视觉审查、权利核查状态，及发布时间。

不得把 API Key、访问令牌或含密钥的下载地址写入元数据、提示词日志或仓库。

## 9. 压缩、加载与回退

首版页面素材的初始体积目标：常用头像不超过 50 KiB，卡片封面不超过 200 KiB，桌面背景不超过 500 KiB。它们是性能预算，不是允许无限压缩破坏质量的硬指标；例外需记录原因。

- 图像母版保留 PNG 或其他适合编辑的原格式，页面优先使用经过质量检查的 WebP。
- 平面矢量纹理与示意背景优先 SVG；外部 SVG 使用前必须清理脚本、外部引用等不安全内容。
- 按实际显示尺寸选择变体，不在列表里加载母版。
- 非首屏插图和地图细节按需加载；明确宽高或比例，避免页面跳动。
- 缺失、拒绝生成、超时或审核不通过均回退到纯色/图形占位，不破坏页面结构。
- 不依赖服务商临时图片链接作为长期地址；取得允许保存的输出后存入项目资产或对象存储。

## 10. 制作流程与验收

1. 创建作品美术设定，确定无剧透范围和素材用途。
2. 先做一张封面和一张背景的小样，不立即批量生产。
3. 在真实页面比例中检查，而不只看孤立图片。
4. 选定方向后生成或制作同系列变体。
5. 审核剧情、角色、空间、时代、来源与权利。
6. 分离文字和标注，裁切、压缩、保存母版与元数据。
7. 验证桌面/手机、深浅背景、长标题、图片加载失败。
8. 审核通过后发布，修改时保留修订记录。

验收清单：

- [ ] 尺寸比例正确，不拉伸；关键主体和标题安全区有效。
- [ ] 封面、背景和头像符合该作品同一套设定。
- [ ] 中文由可控文字层排版，没有将生成乱码作为标题发布。
- [ ] 背景不妨碍文字、节点和关系线阅读。
- [ ] 手机裁切不截断主要主体；主题切换仍可读。
- [ ] 不泄露当前范围之外的信息，包含图片描述和分享预览。
- [ ] 地图底图与标注相符，视觉想象不被当作事实。
- [ ] 生成式素材没有冒充官方海报、真实剧照或事实证据。
- [ ] 母版、发布变体、来源和审核记录完整，不含密钥。
- [ ] 加载体积合理，失效和缺图时有可用回退。

## 11. 图像服务接入边界

当前产品阶段默认采用离线制作：由本地或受控环境的脚本调用图像服务，人工审核后发布静态素材。不要求用户打开作品时实时生成，也不默认向普通用户开放付费生成接口。

接入步骤、密钥安全和当前会话工具的区别见 [图像生成服务接入指南](图像生成服务接入指南.md)。
