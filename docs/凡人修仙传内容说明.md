# 《凡人修仙传》内容数据说明

## 范围与使用方式

实现文件：`src/data/works/mortal.ts`，导出 `export const mortal: Work`，类型来自 `../../lib/types`。

内容范围为忘语原作《凡人修仙传》的人界篇、灵界篇及其中的魔界历险，从韩立进入七玄门到原作渡劫飞升结局。**不包含《凡人修仙之仙界篇》续作、外传、影视改编新增情节，也不是原作全文。**

对外覆盖文案固定为：

> 全书主线分段整理，非逐章全文；原作章节未全部逐章整理

`unitLabel` 为“段”。所有标题均为编辑拟定，40段不是40章原文，不是“已完成原作章节数”，也不能用于计算逐章整理完成率。每段均提供摘要、3段原创复述、3个事件和具体局限说明。复述着重事件因果、人物选择、身份变化及结果，略去大量支线、战斗回合、材料清单和重复闭关过程。

2. [起点作品页与目录，腾讯书籍资源域名](https://wxcs.bookresource.qq.com/book/107580/)：核对起点展示的简介、分卷和末章标题。读取范围是作品页与目录，没有打开章节正文。
3. [百度百科作品词条](https://baike.baidu.com/item/%E5%87%A1%E4%BA%BA%E4%BF%AE%E4%BB%99%E4%BC%A0/54139)：用于分卷梗概、主线转折和人物概况。

## 不确定信息的处理

- 不填写 `originalUnitCount`。官方资源页目录展示2611个条目，QQ阅读页面最新条目标至2558，目录同时含作品相关、公告、外传和其他作品宣传。官方与百科目录都能看到末章标题编号2446及“飞升仙界（大结局）”，但本次未逐条审计纯正文目录，故不把末章编号直接转成已核清的正文章数。
- 不填写任何 `originalRange`。编辑段落跨越多个事件与往返阶段，没有建立准确逐章对照表，不用大概范围冒充真实定位。
- 不采用公开资料中相互矛盾的精确年龄、闭关年数、仙符交易数量与炼神术层数。保留可交叉确认的事件结果。
- 灵王、敖啸、宝花、元魇、涅槃、元刹等人物的分魂、化身、本体须区分，不将击杀化身写成本体彻底陨落。
- 曲魂不等于恢复人格的张铁；银月和珑梦不是普通血缘姐妹；冰凤、冰魄、白瑶怡不是同一个人；慕兰与突兀不能混称。
- 不把田琴儿与辛如音的相似、某些相似面孔或向之礼后期的异常身份扩写成已经证实的转世与完整经历。
- 公开梗概中的“广灵／广陵”统一用“广灵道果”；“春蟠”等剑阵异写、个别药引妖兽名称与准确数量不强行采信。
- 百度作品词条关于“五灵根才能修仙”的概括与书中低阶修行设定冲突，不采用。韩立补金灵根只放在元磁神光等具体修炼条件下说明。
- 掌天瓶更深的时间循环解释、蟹道人续作身份、韩立道祖或大罗境界、失忆重修、仙界最终家庭关系均不纳入本作品数据。

若要升级为准确的逐章索引，需要以合法版本逐章核定正文目录、事件对应章节与资料分歧。本版没有用空段或机械改写伪造数千章内容。

## 图谱语义

- `firstChapter` 是本数据中人物第一次被该段 `characterIds` 收录的编辑段序，不是原作首次出场章号。
- 人物描述说明身份的阶段性变化；关系可以包含后期结局。此图谱没有严格防剧透承诺。
- 现有 `Relationship.type` 只有五类，没有恋爱、同一身份分魂、契约灵兽等专属类型。道侣用 `family`，未成伴侣的互助和情感联系主要用 `ally`，银月与珑梦的特殊联系在说明中明确解释，不能仅凭颜色推断普通盟友关系。
- 师承边保留墨居仁、极阴、木青等带有加害或胁迫的授业，不把 `mentor` 自动理解为善意师父。
- 地图为人界、灵界、魔界及相关小界面的叙事排布。所有x/y在0—100之间，无真实里程或方向含义。
- 区域、城池、宗门、秘境可同时存在。复合阶段事件无法确定单一现场时省略 `locationId`，不补造地点；地点列表也不能当作连续旅行路线。

## 结构校验与改动范围

已使用本机已有Node运行时直接导入数据，并使用已有TypeScript对 `mortal.ts` 与 `types.ts` 单独执行严格无输出类型检查。没有安装依赖，没有启动全项目，没有修改类型、入口、页面、封面或配置。

校验项：

- 40段的 `order` 从1到40连续。
- 每段3个原创复述自然段、3个事件，摘要与编辑说明非空。
- 事件ID全作品唯一，人物、地点、来源、关系与段落ID各自唯一。
- 段落、事件、关系中的所有引用ID均存在；事件人物与地点归属于对应段落的引用集合。
- 人物 `firstChapter` 与本数据首次收录段序一致。
- 坐标范围合法；53个地点全部被主线段落引用。
- 覆盖声明、`isFullText: false`、不填写原文章数与范围符合本版口径。
