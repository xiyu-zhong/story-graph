# 图像生成服务接入指南

> 用途：为故事图谱制作背景、封面及其他经过审校的静态素材。
> 默认方案：先通过本地/受控脚本调用 OpenAI 图像生成 API，不先搭建公共生图后台。
> 本文是接入步骤，不表示已配置密钥、已实现调用脚本或已发生任何付费生成。

## 1. 模型、ChatGPT、API 与会话工具的区别

- 对话所使用的 GPT 模型与图像生成工具是不同层面；使用 GPT 模型不代表当前产品自动提供所有 OpenAI 工具。
- ChatGPT 网页中的图片生成功能属于 ChatGPT 产品体验，不能直接把其会员权限当成项目的 API 凭证。
- OpenAI 提供独立的图像生成 API，可通过程序生成或编辑图片。
- 通过本地脚本调用 API，不需要先搭建 MCP。
- 如果希望生图能力作为会话的原生集成工具被发现和调用，可以另行接入提供对应能力的 MCP 服务；不能把普通图像 API 地址直接当作 MCP 服务地址。
- ChatGPT 与 API 独立计费，额度、模型访问和认证要求以实际 API 账户为准。

官方资料：

- [OpenAI 图像生成指南](https://developers.openai.com/api/docs/guides/image-generation)
- [ChatGPT 与 API 计费说明](https://help.openai.com/en/articles/9039756-billing-settings-in-chatgpt-vs-platform)

## 2. 推荐接入路径

```text
作品美术设定与任务模板
  → 本地或受控环境的素材生成脚本
  → OpenAI 图像生成 API
  → 保存图片母版与制作记录
  → 人工审查
  → 裁切、排字、压缩
  → 发布为项目静态素材
```

适合当前设计阶段：不需要在前端暴露密钥，不需要让每次浏览页面触发费用，也能先验证画风和内容质量。

图像服务可以后续替换；产品的素材记录与模板不绑定某个模型名称。服务商支持的生成尺寸不一定等于最终交付尺寸，按 [视觉素材规范](视觉素材规范-v1.0.md) 后处理。

## 3. 你需要准备什么

1. 在所在地区可正常使用、符合服务条款的 API 账户。
2. 开通 API 计费与目标图像模型访问；按服务商要求完成必要的账户或组织验证。
3. 创建项目专用凭证，仅赋予所需权限。
4. 确认首轮生成预算、数量，以及允许发送给服务商的提示词和参考素材。
5. 在本地环境配置凭证，不通过聊天传递。

具体模型可用性、费用与验证要求按官方控制台确认，不根据 ChatGPT 套餐或对话模型推断。

如果账户无法使用该服务，应选择合法可用的其他提供商，不通过不可信中转站转交密钥或素材。

## 4. 密钥与配置

采用环境变量。配置名称约定如下，值由实际账户决定：

```text
OPENAI_API_KEY=<只在本地或受控密钥环境配置>
OPENAI_IMAGE_MODEL=<账户实际可用的图像模型标识>
```

这只是变量说明，不是有效凭证或已经生效的配置。

安全要求：

- 密钥不得发到聊天、写进 Markdown、截图或提交 Git。
- 不得使用暴露给浏览器的前端环境变量，如 `NEXT_PUBLIC_*` 来保存密钥。
- 优先使用系统密钥管理或仅当前终端会话的环境变量。
- 如使用本地 `.env` 文件，先确认被 Git 忽略且限制文件权限；仓库内只提供无真实值的示例文件。
- 日志不能打印认证头、完整环境变量或凭证；参考素材也不应无必要地写入公开日志。
- 对意外泄露的密钥立即撤销并替换，仅删除聊天或文件副本不够。

不得为了“检查有没有配置”而读取、回显整份用户密钥文件。验证时只检查指定变量是否存在，并通过小额测试确认权限。

## 5. 调用脚本需要做什么

服务商与预算确认后，再实现脚本；当前不要求先建设业务后端。

最小能力：

1. 读取指定的环境变量，缺失时清晰报错且不输出密钥。
2. 读取生成任务：用途、提示词、比例、模型支持的尺寸与质量、输出位置。
3. 默认一次一张，显式展示非敏感任务参数，付费调用前确认数量与预算。
4. 调用官方图像生成接口；编辑任务按支持情况调用对应编辑能力。
5. 正确处理实际返回的图片数据，保存为母版，不用 `.png` 扩展名冒充其他格式。
6. 保存模型、提示词、参考素材标识、生成时间、尺寸等制作记录，但不含凭证。
7. 校验输出是可打开的有效图片，进入视觉与内容审查，不能生成后直接自动发布。
8. 处理超时、拒绝、额度不足、模型无权限和空结果；不无限重试。

网络超时可能无法确认任务是否已经执行，不能盲目重复发起付费请求。预算告警也不等于硬性消费上限；本地调用限制与服务商配置都需要确认。

## 6. 接入成功的验证标准

- 指定环境变量可读取，但不会出现在日志中。
- 能用一个不涉及敏感资料、无剧透的简单提示词生成一张图片。
- 图片实际可打开，格式与尺寸可检测。
- 费用和调用记录能够在 API 账户中核对。
- 输出保存在明确位置，并有不含密钥的制作记录。
- 未配置、无权限和生成失败时给出可操作错误，而非空白图片。
- 测试成功后才按素材任务逐步生成，不立即启动批量任务。

## 7. 如果要作为会话原生工具接入

另一条路径是使用真实存在的图像生成 MCP 服务。需要提供：服务端点、服务说明、传输方式和认证方式；服务必须实际暴露生图工具，而不只是转发普通聊天请求。

流程：

1. 选择可信服务，或者自行部署封装官方 API 的 MCP 服务。
2. 确认素材与凭证的传递路径、访问权限、存储方式和成本。
3. 使用集成配置入口登记真实的 MCP 地址，在安全授权界面填写认证信息。
4. 连接后检查实际工具列表，再进行一张图的小额验证。

在连接前不假定某个服务地址存在，不把普通 API 地址当作 MCP，也不声称配置一个聊天模型就自动获得生图能力。

## 8. 未来项目后台扩展

只有需要编辑人员在后台生成素材时，才把离线脚本升级为受控服务：

```text
后台编辑界面 → 有鉴权的服务端任务 → 图像服务 → 私有待审素材 → 审核发布
```

届时补充权限、限额、队列、去重、失败重试、对象存储、审计与费用记录。不得让任意前端请求直接调用付费 API，也不应默认把生成结果立即公开。
