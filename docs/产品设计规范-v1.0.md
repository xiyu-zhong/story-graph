# 故事图谱：产品设计规范 v1.0

> 状态：当前产品设计基线。用于页面设计、内容整理与原型验收，不代表功能已经实现或用户假设已经验证。
> 本规范承接三图核心方向，并替代早期方案和跨媒介草案中的冲突约定。视觉素材遵循 [视觉素材规范 v1.0](视觉素材规范-v1.0.md)。
> 规范用语：“必须/不得”为验收约束；“默认”为当前决策；“可选/后续”为不阻塞首版的扩展。

## 1. 定位与范围

产品以流程图、人物关系图、地图三个平级入口，帮助用户阅读和探索一部作品的完整故事。用户可以顺着叙事推进，也可以从人物、关系或地点进入故事。

- 流程图必须覆盖已收录范围内的全部内容单元，支持逐级展开；不得以仅有搜索列表替代。
- 人物关系图必须覆盖已收录人物与关系；完整收录不等于一次铺开全部节点。
- 地图必须表达故事地点与有依据的空间联系，可采用真实地图、架空地图、室内空间图或地点拓扑图。
- 点击章节、场景、单集等内容单元，必须能够进入相应的完整故事叙述。
- 搜索、摘要和问答均为辅助能力，不改变三图为核心的产品结构。
- 首版以小说内容闭环落地；产品模板同时兼容电影、电视剧，并以小样本验证兼容性。完整上线三种媒介不是首版验收条件。
- 不将原文阅读器、视频播放平台、创作工具或社交社区纳入首版。

“完整故事”默认指独立整理的完整情节叙述：覆盖本单元关键行动、动机、冲突、转折和结果，保留必要上下文，不是只有一句摘要，也不承诺逐字或逐镜头复刻。原文、原视频与大段对白另属授权内容能力。

## 2. 内容组织与版本边界

### 2.1 核心概念

| 概念 | 必须表达的含义 |
|---|---|
| 作品集合 | 可选的系列、改编等导航集合，不自动合并剧情事实 |
| 作品 | 一次独立创作或改编；原著小说、改编电影、改编电视剧分别建作品 |
| 作品版本 | 具体翻译、编辑、删节、剪辑或发行版本，所有来源位置与消费进度绑定它 |
| 内容单元 | 作品内部的导航结构，如卷、章、季、集、场景，允许层级省略 |
| 事件 | 故事中发生的事情，不等同于一章、一集或一个场景 |
| 来源位置 | 某条叙述在当前版本中的位置，可为章节/段落或集内起止时间码 |
| 信息条目 | 一条具体陈述及其来源、揭示位置、陈述性质和审校状态 |

结构为“作品 → 版本 → 内容单元树”。内容单元通过来源位置连接事件；事件与人物、关系和地点相连接。

同一事件可以有多个来源位置，一个内容单元也可以包含多个事件。重述、回忆、不同视角必须保留各自的叙述语境；有矛盾的说法不得强行归并为唯一真相。

### 2.2 媒介预设

| 项目 | 小说 | 电影 | 电视剧 |
|---|---|---|---|
| 导航层级 | 卷 → 章，卷可省略 | 故事段落 → 场景，段落可省略 | 季 → 集 → 场景，季可省略 |
| 流程图默认节点 | 章 | 场景或整理后的故事段落 | 集 |
| 详情主单位 | 章 | 场景/段落，上层可查看整片故事 | 集，可下钻场景 |
| 进度 | 已读完某章 | 当前版本看到的时间位置 | 当前版本、季集标识、集内位置 |
| 来源定位 | 章、段落；页码仅适用于明确版本 | 当前剪辑版本的时间码 | 当前版本的季、集、集内时间码 |
| 专属资料 | 译名、注释、卷章目录 | 片长、剪辑信息、演职员 | 单集信息、季集目录、连载状态 |

不得强迫电影使用固定三幕结构，也不得强迫每集电视剧包含相同的戏剧环节。编辑整理的分段、标题与原作目录必须明确区分。

### 2.3 必须保持独立的对象

- 角色与演员：角色属于故事，演员属于现实演职人员，通过出演关系关联，允许一人多角和一角多人。
- 故事地点与取景地：默认地图展示故事空间，取景信息是独立的可选图层。
- 原著与改编：分别维护人物、关系、事件；同名不等于相同事实。
- 作品版本与内容修订：作品剪辑/译本版本不同于本产品的审校修订，两者均可追溯。

跨改编对应允许一对多、多对一、缺失与待确认；首版只需保留独立标识和关联空间，不实现自动对齐。

## 3. 对象内容要求

| 对象 | 必需内容 | 可选扩展 |
|---|---|---|
| 人物 | 当前可展示称呼、介绍、参与事件、关系、来源 | 成长、目标、立场变化、出演信息 |
| 势力/群体 | 名称、属性、成员关系、来源 | 所属空间、阶段变化 |
| 事件 | 经过、参与者、来源、涉及地点或未知状态 | 相对时间、因果、目标、关系变化 |
| 关系 | 双方、方向、语义、成立依据、变化依据 | 共同故事、阶段对比 |
| 地点 | 名称、空间层级、定位方式、相关故事 | 多次到访、地点状态变化、取景资料 |
| 信息条目 | 陈述、来源位置、揭示范围、性质、审校状态 | 争议与替代说法 |

信息性质至少区分：原作明确呈现、人物说法、编辑解读、待核实。未知允许为空并显示原因，不为填满模板而生成事实。

关系必须表达语义和方向。“甲怀疑乙”不等于“双方敌对”，“曾是盟友”不等于“此刻仍为盟友”。顺序相邻也不自动构成因果。

## 4. 六类页面模板

### 4.1 作品入口

必须包含：作品与媒介信息、当前版本、内容覆盖范围、三图入口、继续探索、已读/已看记录、全貌/跟随模式、素材与叙述来源说明入口。

必须区分：作品尚未完结、产品尚未整理、内容待审校、内容因进度隐藏。不得统称“未解锁”。

封面和背景为可替换视觉素材；缺图必须有稳定的文字/图形占位，不阻止进入作品。

### 4.2 内容单元详情

```text
单元身份：作品 / 版本 / 卷章或季集或场景 / 来源范围
快速概览：本单元讲什么、主要人物、地点与叙事线
完整故事：连续叙述；人物、地点与事件可定位到三图
事件结构：展开事件链或多条叙事线
本单元变化：人物、关系、地点、目标等实际变化
前后连接：相关前文、前一单元、后一单元
内容依据：来源位置、整理/解读标识、纠错
```

完整故事为主体。没有冲突、变化或结局的单元，不强行填充对应槽位。来源未覆盖整章/整集时必须标明“部分整理”，不得标为完整故事。

### 4.3 事件详情

必须包含经过、参与人物、相关来源位置、地点/未知状态；可包含相对时间、因果、状态变化。明确回忆、转述、梦境等叙述性质。

只展示当前范围已经揭示的内容；同一事件在后续重述中新增的信息，不得提前并入当前详情。

### 4.4 人物详情

必须包含当前范围的介绍、称呼、局部关系、参与故事和地图入口。全貌介绍与阶段介绍区分；未揭示的别名、真实身份、终局状态不能提前显示。

成长、目标、立场、演员资料按媒介和作品启用，不占用所有作品的固定版面。

### 4.5 关系详情

必须显示双方、关系语义/方向，以及建立和变化的故事依据；支持通过共同事件进入章节或场景。全书历史关系与当前阶段关系明确区分。

“有什么联系”可展示连接路径；“怎么认识的”必须以共同事件回答，不能用最短路径代替。

### 4.6 地点详情

必须显示空间层级、定位方式、相关内容单元与事件、到访人物。多次到访保留各次故事位置，不能合并成一次旅程。

没有可靠坐标或移动依据时，使用示意、拓扑或未知状态；不得生成精确地理断言。

## 5. 三图展示与联动

### 5.1 流程图

- 支持全书/全片/全剧概览，以及卷、季、章、集、场景、事件的适用层级。
- 默认叙事顺序，回忆、插叙和平行线明确标记。
- 顺序、因果和叙事分支采用不同图例，不暗示原作不存在的剧情选择。
- 缩放、展开和折叠不得使部分已收录单元失去访问入口。

### 5.2 人物关系图

- 全部人物可访问，使用分组、折叠和聚焦管理复杂度，不以固定“前 30 人”作为内容覆盖边界。
- 支持全貌关系和阶段关系；点击人物与连线分别进入对应详情。
- 当前范围的排序与重要性不能依赖未来剧情统计。
- 尽量保持布局稳定；颜色不能作为关系类型的唯一表达。

### 5.3 地图

固定支持四种表达预设：真实地理、架空地图、室内空间、地点拓扑。产品模板支持四类，不要求首版全部渲染方式同时完成。

必须区分“沿叙事浏览地点”和“沿人物查看旅程”。场景切换、台词提及、回忆地点均不自动算作当前人物到访。

生成式底图只提供视觉表达，坐标、地点与路线必须独立审校。生成图不得作为事实来源。

### 5.4 共用状态与联动表

共用状态：作品版本、当前内容单元、选中对象、展开层级、筛选条件、探索模式。消费进度独立保存。

| 操作 | 流程图 | 关系图 | 地图 | 详情 |
|---|---|---|---|---|
| 选内容单元 | 定位并展开事件 | 突出参与人物与变化 | 突出本单元地点 | 完整故事 |
| 选事件 | 定位来源单元 | 突出参与人物 | 定位发生空间 | 事件经过 |
| 选人物 | 突出参与单元 | 聚焦相关人物 | 展示有依据的旅程 | 人物故事线 |
| 选关系 | 突出共同事件 | 展示关系变化 | 按需定位共同地点 | 共同经历 |
| 选地点 | 突出相关单元 | 突出相关人物 | 聚焦空间层级 | 地点故事 |

选择对象不自动修改已读/已看记录。切换主图保留上下文，提供返回、面包屑、清除筛选与恢复视野入口。

## 6. 时间、进度与防剧透

必须分别表达：

1. 叙事位置：原作何时讲述这段内容。
2. 故事时间：事情在故事世界中何时发生，允许相对顺序、范围和未知。
3. 信息揭示位置：某条身份、关系、陈述何时可以被读者/观众获知。

不得仅用人物首次出场时间控制整个简介；不得因为回忆事件发生得早就提前展示。

### 默认模式

- 首次进入提供“全貌探索”和“跟随阅读/观看”的明确选择；未选择时仅显示无剧透介绍和安全目录。
- 全貌探索允许查看已收录的完整内容，但不等于原作已完结或内容已经全量整理。
- 跟随模式以用户确认的连续消费边界为首版规则。必须说明此前单元按已读/已看处理；未来非连续观看另行支持，不偷偷推断。
- 小说以“已读完”定义边界。影视以版本内时间位置定义边界；场景未看完不得展示后半场事件。
- 临时浏览、回顾旧章与修改消费进度是不同操作。超前探索须明确确认。
- 版本切换只有在存在可靠映射时才迁移进度，否则要求重新确认；不得按时长比例迁移。

搜索、排序、头像、封面、背景、标题、地图、替代文字和分享预览均服从同一信息边界。不得用“还有几条隐藏关系”等方式暗示未来。

## 7. 内容生产与质量

发布流程：登记作品版本与权利 → 建内容目录和来源锚点 → 整理事件及实体 → 撰写完整故事 → 人工审校 → 多进度预览 → 发布。

必须检查：

- 关键陈述、关系和移动轨迹能追溯到来源。
- 身份消歧、别名合并和事件归并不超前揭示信息。
- 事实、人物说法与解读明确区分。
- 影视不能仅凭字幕抽取就宣称覆盖全部动作与画面信息。
- 版权、素材来源和使用许可分别核查；不存在通用的安全字数或片段时长。
- 来源链接仅使用实际可用地址，不假定任意平台支持时间跳转。
- 纠错入口首版提供；公开内容由审校流程修改，不自动合并用户反馈。

内容状态至少区分：未整理、草稿、待审校、已发布、已撤下；记录修订说明。模板升级不得静默改变已发布字段的含义。

## 8. 页面与视觉原则

- 三图是平级主入口，任何一图都可成为主画布。
- 桌面支持主图加详情，另两图可展开为辅窗；不强制三图平分屏幕。
- 手机使用共享状态的三图切换，完整故事可展开为阅读区。
- 图谱和正文优先可读，背景保持低干扰；作品主题视觉集中在封面、入口和故事插图。
- 文字和交互标签独立于插画，不能把图谱信息画死在背景中。
- 动画表达变化，不作为理解的唯一条件；支持减少动效。
- 详细尺寸、图层、交付和素材验收遵循 [视觉素材规范 v1.0](视觉素材规范-v1.0.md)。

## 9. 首版与后续能力

### 首个原型必须跑通

在一段连续故事中完成：流程概览 → 选择单元 → 阅读完整故事 → 查看人物与关系 → 定位地点 → 返回并推进下一事件。

使用小说、电影、电视剧三个小型结构样本检验同一套模板，不要求同时完成三个生产级内容库。

当前收录《奥德赛》《西游记》《凡人修仙传》《射雕英雄传》四个故事世界，共用同一套三图交互。小说与史诗按已核实的回/卷目录组织原创情节整理，来源版本与审校程度单独说明；超长作品在未完成逐章整理前，必须标注实际的主线分段覆盖，不得把编辑段落数冒充原作章节数。

当前实现阶段以全貌探索为先，明确告知含后续剧情；底部进度轴仅定位浏览位置，不对外承诺严格防剧透。信息级揭示规则仍是后续跟随模式的验收基线，未完成前不得以“安全模式”命名。

### 后续可选

人物专属故事线、阶段变化对比、目标/悬念线、地点历史、关系演变、线索图层、原著与改编对照、人物知情范围、读后伏笔、授权播放。

这些是扩展，不成为每个内容单元的必填字段。不先建设万能模板编辑器或公共生图服务。

## 10. 验收清单

- [ ] 三图均为直接可达的主入口，切换后保留当前选中对象。
- [ ] 全部已收录内容单元和人物可访问，折叠不丢内容。
- [ ] 章节/场景/单集详情有完整叙述，不只是摘要。
- [ ] 关系可查看依据和变化，最短路径不冒充共同故事。
- [ ] 地图不把镜头切换、回忆或台词提及当成旅行。
- [ ] 室内故事可以使用空间图，未知地点不会被强行赋予坐标。
- [ ] 演员与角色、原著与改编、不同版本不会错误共用事实。
- [ ] 同一事件的多次讲述保留来源与各次揭示的信息。
- [ ] 进度前、边界点、边界后三种情况下检查图、正文、图片与分享。
- [ ] 只看半个场景不会看到后半段剧情；切换版本不静默迁移进度。
- [ ] 缺图、部分内容、待审校、未完结和隐藏内容有不同状态。
- [ ] 关键内容有来源，生成图不会被用作剧情或地理证据。
- [ ] 首版样本在手机上可阅读完整故事并完成三图跳转。

## 11. 文档维护

当前生效入口见 [文档索引](README.md)。早期产品方案与 v0.1 跨媒介草案仅保留为讨论历史。

结构和交互规则作为设计基线；当前作品为《奥德赛》《西游记》《凡人修仙传》《射雕英雄传》，应用风格确认为科幻方向。模型服务商、付费生成预算和美术批量制作以实际样本另行确认。修改已确定规则时更新版本与变更说明，不并列维护互相冲突的规范。
