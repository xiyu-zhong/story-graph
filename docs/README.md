# 故事图谱文档

## 当前生效规范

1. [产品设计规范 v1.0](产品设计规范-v1.0.md)：三图核心定位、小说/电影/电视剧模板、六类详情、版本与进度边界、三图联动、内容质量及原型验收。
2. [视觉素材规范 v1.0](视觉素材规范-v1.0.md)：封面与背景的比例尺寸、构图、文字分层、地图底图、风格设定、生成任务、来源与验收。
3. [图像生成服务接入指南](图像生成服务接入指南.md)：通过本地受控脚本接入 OpenAI 图像 API，解释 ChatGPT/API/会话工具区别、密钥安全、测试与成本控制。

规范状态：已进入开发，技术运行说明见 [项目 README](../README.md)。规范描述目标契约，不表示每个验收项均已实现。封面与背景先采用程序绘制和 Three.js 实时效果；没有配置图像服务密钥，也没有执行付费生图。

默认先完成小说样本的三图闭环，同时用电影、电视剧小样验证模板。完整故事采用独立整理的情节叙述，原文和原视频另属授权能力。图片采用离线生成/制作、人工审查、静态发布，不先做公共生图后台。

当前作品为《奥德赛》《西游记》《凡人修仙传》《射雕英雄传》，风格为科幻叙事终端；电影、电视剧仍保留模板兼容性。模型访问和付费生图预算另行确认。实际已实现范围与内容粒度见项目 README 和各作品内容说明。
