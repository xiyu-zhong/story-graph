# 《奥德赛》内容说明

## 数据范围

实现文件：`src/data/works/odyssey.ts`，按 `src/lib/types.ts` 的 `Work` 类型导出 `export const odyssey: Work`。

- 24卷，`order` 连续为1—24；每卷独立摘要、4段原创中文复述。
- 共96段复述，正文复述约9,499个字符（含标点，不含摘要、事件和其他字段）。
- 99个事件：第4卷5个，第12卷6个，其余各4个。
- 50个人物／神灵／动物角色节点、55条关系、30个地点节点。
- 5条来源记录，6组叙事阶段；所有卷题与阶段名都是编辑题名。
- `id='odyssey'`、`unitLabel='卷'`、`accent='#62c5e8'`、`cover='/art/odyssey.svg'`。
- `coverage.isFullText=false`：这是覆盖二十四卷主要情节的中文导读，不是原文全文、逐行翻译或现代中文译本摘录。

## 来源与使用方式

所有以下URL均经过搜索发现或已发现页面链接，并实际抓取确认可读，不根据规律拼接未经确认的来源地址。

1. [Project Gutenberg：Samuel Butler英文译本](https://www.gutenberg.org/files/1727/1727-h/1727-h.htm)
   - 1900年公版译本，主要事实依据。抓取全文，检查BOOK I—XXIV的目录、开头、结尾及关键段落。
   - 人名统一用常见希腊形式，例如Ulysses→奥德修斯、Minerva→雅典娜、Neptune→波塞冬；原译异名保留在角色aliases中。
   - 不采纳译者序言中关于女性作者、特定西西里地理位置的个人假说。
2. [Wikisource：The Odyssey (Butler)](https://en.wikisource.org/wiki/The_Odyssey_(Butler))
   - 核对传统24卷目录、各卷题旨与公版版本说明。
   - 与Gutenberg是同一英文译本的不同呈现，不把它们算作两份独立译文证据。
3. [SparkNotes：分组章节梗概](https://www.sparknotes.com/lit/odyssey/sparklets/)
   - 交叉核对全书叙事结构，不照搬其文字，也不把分组压缩后的先后次序当成精确卷界。
4. [SparkNotes：第15—16卷](https://www.sparknotes.com/lit/odyssey/section8/)
   - 对照少年返程、预言者登船、猪倌童年、父子相认与城中阴谋的交叉叙述。
5. [SparkNotes：第21—22卷](https://www.sparknotes.com/lit/odyssey/section11/)
   - 对照试弓、认回忠仆、封门、战斗与甄别家仆。
   - 发现并排除具体错误：该页分析段把欧律马科斯之死归于忒勒马科斯的矛，但公版正文及该页自身摘要均为奥德修斯射杀；数据采用后者。
   - 该页摘要把辨认伤疤写作foot，数据按正文保留腿部猎伤，不采用脚部定位。

复述采用重新组织的中文叙述，不拼贴任何现代中文译文；现代梗概仅作为查错工具。字符数量与人物数量不等于全文或人物百科覆盖率。

## 叙事层与地图约定

- 地图坐标只是0—100的布局值，没有经纬度意义，不承诺距离、朝向、速度或地中海真实路径。
- 神话地点与现代地名的对应有争议；不把独眼巨人岛、喀耳刻岛、卡吕普索岛或海峡强行定位到某个现代地点。
- `locationIds`是场景检索集合，不是单一主人公的时间线轨迹，不应依章节顺序直接连成一条真实航线。
- 事件描述明确标注【当下】【转述】【倒叙】【歌中】【回忆】。第9—12卷讲述现场仍是斯刻里亚王宫，远方航程都是过去经历。
- 特洛伊属于战友转述／歌唱；法罗斯属于墨涅拉俄斯回忆；叙里埃属于猪倌童年；帕尔纳索斯属于伤疤回忆。它们不是当下奥德修斯的新增站点。
- 第14卷克里特、埃及等假自传不被当作真实路径录入；第23卷携桨出行仍是未完成的未来预言，不画成既成行程。
- `StoryEvent`只有一个可选`locationId`。少数合并事件用主要场景作索引，其余转场在描述与`editorialNote`说明，不假装一个坐标能代表整段航程。
- 城港、斯刻里亚近海、王宫、亡者之境是明确说明过的聚合节点，不对应单一现代考古点。

## 人物、关系与解释边界

- `firstChapter`以本整理的`chapter.characterIds`首次收录为准，含被提及或回忆的人物，不等于此人物第一次在史诗当下亲自登场。例如奥德修斯为1，开始当下行动则为5。
- 门托耳本人只承担其实际发言；雅典娜借用他的样貌仍记为雅典娜，不制造分身人物重复边。
- 关系的`chapterIds`指所描述关系在本整理中呈现的卷，不是泛填所有章节；检查每条边的两端都被相应卷索引。
- `family`用于实际亲属／夫妻；没有用这一类别把瑙西卡娅与奥德修斯的潜在婚事写成婚姻。
- 喀耳刻、艾俄洛斯、卡吕普索等关系有变化；受限于静态关系类型，描述写明从阻挠到帮助或由帮助转为拒绝的过程。
- 不把第19卷“珀涅罗珀已识破伪装”这一争议解释定为事实；决定性公开相认保留在第23卷。
- 不省去十二名女仆被绞死与墨兰提俄斯遭肢解，但也不把史诗主奴秩序的裁决写成现代伦理上的当然正义。

## 具体限制与未做事项

- 没有按希腊文行号逐行校勘，也未提供第二种独立公版译本的全卷对照；主要依据是Butler译本，并用另一站点的同版目录及现代梗概查错。
- 不是全人物、全典故、全祭礼名录，长名单有压缩；50个角色中包括神灵、亡灵和老犬。
- 现有`Work`类型没有结构化的叙事层、事件时间或地点角色字段，因此依靠事件标签、region与编辑说明区分。若消费端忽略这些说明并把所有地点连线，仍可能产生误导；本任务未修改类型或地图组件。
- 未安装依赖、未启动服务、未运行全项目构建或浏览器验收；封面只按约定引用`/art/odyssey.svg`，没有在本任务创建或修改图像。
- 本任务只写入`src/data/works/odyssey.ts`与本说明文档，不修改其他项目文件。
