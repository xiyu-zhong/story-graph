# 《射雕英雄传》内容说明

## 范围与版本选择

本作品条目用于 Story Atlas 的章节阅读、人物关系与地图浏览。作品 ID 为 `condor`，媒介为小说，章节单位为“回”，数据文件导出 `condor: Work`。

采用金庸在 **1970—80年代形成的修订版（通常称第二版、新版、流行版）四十回框架**，不是1957—1959年报刊连载版，也不是世纪新修版，更不是电视剧《铁血丹心》的分集结构。

主要目录依据是[远流出版社《射鵰英雄傳》亮彩映象修订版全四册出版页](https://www.ylib.com/activity/YLib2026/book-info.asp?itemNo=D600N)。该页明确说明保存1970年代修订内容，并列出四十回目录。这可以支持本条目的版本家族及回目选择，但**不等于证明远流、明河、1994年三联各印次每个字都一致**，本项目也没有逐页比较这些印本。

回目由繁体转为简体，保留该修订体系中的：

- 第3回《大漠风沙》，不混用新修版《黄沙莽莽》。
- 第10回《冤家聚头》，不混用《往事如烟》。
- 第19回《洪涛群鲨》，不混用《洪涛鲨群》。
- 第20回《窜改经文》，不混用《九阴假经》。
- 第31回《鸳鸯锦帕》，不沿用部分聚合目录的“鸯鸳”误植。

每回固定有3段实质性复述、3个场景事件，另有摘要、阶段、来源和编辑说明。章节 ID 连续为 `condor-01` 至 `condor-40`；事件 ID 为回 ID 加 `-e1`、`-e2`、`-e3`。段落总长度按每回约200—350字的导读规模编写，不是把原文切成120段。

人物包含郭、黄、杨、穆家庭，江南七怪各自独立的七个节点，全真七子各自独立的七个节点，五绝、周伯通、桃花岛门人、一灯及渔樵耕读、蒙古王族与哲别、赵王府高手、丐帮人物等。不是全书所有具名人物的穷尽名录。

## 已核对的内容与仍有限的内容

**已经核对：**四十回回目及顺序、修订版与新修版的关键题名差异、主要故事线、关键身份区别、桃花岛五师遇害与铁枪庙毒发的因果。对二手来源的简单归纳没有照单全收。

**没有完成：**授权修订版正文的逐页逐回校勘、每个事件的严格起止页、每个角色首次被原文点名的页码、各印次词句和地名的全量比对。逐回叙述由二手梗概、读者分回评论及已知叙事顺序组织，跨回出入场和旅程有所压缩。程序校验只能证明结构完整，不能证明文学事实全部正确。

各回 `editorialNote` 明示这一限制；`sourceIds` 是本回编辑参考资料，不代表每个来源都独立证明本回每一句话。没有伪造原文段落坐标，未设置 `sourcePositions` 或假页码。`originalRange` 仅表示对应回目。

## 身份、关系与时态

- 杨铁心与“穆易”是同一人，用 `aliases` 表示，不拆成两个节点。
- 杨康的生父是杨铁心，养父是完颜洪烈；“完颜康”是别名。
- 穆念慈是杨铁心养女，不是他的亲生女儿。
- 欧阳锋与欧阳克公开为叔侄，实际为生父子，关系说明同时保留两个层次。
- 裘千仞是真正的铁掌帮主，裘千丈是冒用弟名的孪生哥哥。彭长老与彭连虎也分别建档。
- 桃花岛五位死者为朱聪、韩宝驹、南希仁、全金发、韩小莹。张阿生早在大漠黑风双煞一战中死亡，不纳入桃岛五师。
- 王重阳、陈玄风、冯氏、曲灵风等在后续回目中常由转述或遗迹进入索引。事件标签用“回忆”“转述”“遗体现场”“遗迹”等说明，不意味着他们当场活着出现。
- `characterIds` 和 `locationIds` 从事件引用去重生成。`firstChapter` 是人物第一次进入**本编辑索引**的回次，包括回忆、转述等，不是原文首次提名或严格的首次实体出场。例如欧阳锋先出现在旧论剑转述里。
- 关系的 `chapterIds` 表示可以结合阅读的证据回目，可以跨回追索事实，不要求关系两端在每一条证据回都面对面出场。关系描述保留了从同盟到反目、从误会到澄清等变化。
- 当前通用类型没有单独的爱情关系枚举，郭黄相恋等使用 `ally` 并以中文标签解释；已经成婚或明确亲属关系使用 `family`。这不是将恋爱等同于普通结盟。

全部人物资料和关系均可包含后段情节，**本条目全剧透，不提供防剧透保障**。

## 地图语义

29个节点覆盖蒙古、张家口、金中都、宝应、太湖归云庄、牛家村、临安宫禁、嘉兴、桃花岛、东海、洞庭君山、铁掌峰、黑沼、一灯隐居处、大理宫廷回忆、西征营地、雪峰、撒马尔罕和华山等空间。

`x`／`y` 在0—100范围内，仅是编辑排布：

1. 不表示经纬度、朝代疆界、精确路程、相隔天数或现实测绘坐标。
2. 一回可能包含几个人物的不同地点，以及旧事中的地点。回序和连线不是郭靖的一条连续旅行路线。
3. “大理宫廷（回忆）”与“一灯隐居山寺”分别建档，不让求医路线凭空穿过旧宫廷。
4. 大漠崖顶、海上荒岛、湍江险滩、江南行旅、西征军营等为合并或未作实址比附的节点。军营会移动，海上位置不精确，小说中的禿木峰不硬套现代坐标。
5. 第40回的华山与蒙古两处用于故事收束，不代表图上直线可还原现实行程。
