# 故事图谱 · Story Atlas

一个以流程图、人物关系和故事地图为核心的交互式叙事探索应用。当前收录《奥德赛》《西游记》《凡人修仙传》《射雕英雄传》。

## 运行

需要 Node.js 24（见 `.nvmrc`）。在安装了 nvm 的终端中：

```bash
nvm use
npm install
npm run dev
```

默认只监听本机 `127.0.0.1:3000`，终端会显示实际地址。依赖已经安装时，无需再次运行 `npm install`。

```bash
npm run typecheck
npm test
npm run build
npm start
```

浏览器测试：

```bash
npm run test:e2e
```

本机测试配置默认使用 macOS 已安装的 Chrome；其他系统可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指向浏览器，或调整 Playwright 配置使用已安装的 Chromium。

## 技术与结构

- Next.js App Router、React、TypeScript。
- Three.js 绘制首页星点、立体球体与轨道。浏览器不支持 WebGL 时使用静态回退；支持减少动效。
- SVG 实现可拖动的人物图、关系选择与地图探索。
- 本地存储保存收藏与阅读位置，不要求注册账号。
- 内容以结构化静态数据加载，不需要数据库或图像服务密钥。

```text
src/app/                  页面、路由、整体样式
src/components/           作品库、探索器、三图与 Three.js 场景
src/lib/                  共用内容类型、搜索与图布局
src/data/works/            四部作品的原创情节和图谱资料
public/art/               四张原创矢量概念封面
tests/                    内容引用测试、浏览器交互测试
docs/                     产品规范、视觉规范与内容说明
```

## 使用

1. 在作品库选择一个故事，进入全貌探索。
2. 点击流程节点，在右侧阅读情节、人物、地点和事件；“沉浸阅读”打开宽阅读区。
3. 点击人物或关系可在关系图中聚焦；人物节点和画布可以拖动。
4. 点击地点查看关联故事；地图区域选择器可筛选位置。
5. 搜索人物、别名、地点或情节，快捷键为 `⌘/Ctrl + K`。
6. `←/→` 切换探索单元；收藏和“记住当前阅读位置”保存到当前浏览器。
7. 分享按钮复制含当前单元、视图参数的本地链接；如需他人访问，必须先部署到其可访问的地址。

## 内容边界

- 内容是原创中文情节整理，不是原作全文或授权阅读/播放服务。
- 《奥德赛》按二十四卷、《西游记》按一百回、《射雕英雄传》按四十回组织；《凡人修仙传》按编辑主线段落组织，不把段落数冒充数千原作章节。
- 《射雕英雄传》区分小说版本与影视改编；回目覆盖不等于逐页校勘，章节衔接与回顾内容的处理见其内容说明。
- 各作品的具体来源、审校边界和覆盖范围在作品内“内容说明”及数据文件中明示。
- 当前是**全貌探索，包含后续剧情**。进度轴用于定位，不是严格防剧透过滤。信息级防剧透与跨版本进度迁移尚未实现。
- 地图是故事空间示意，不是精确地理。虚线表示当前单元关联地点，不自动代表人物实际移动。
- 图谱仅展示已整理的人物和关系，不宣称穷尽原作所有人物、场景和解读。
- 人物资料、跨章事件和地图仍需持续内容审校，结构测试不能证明文学事实完全正确。
- 四张 SVG 封面为项目原创程序绘制概念图，不是官方海报、真实剧照或 AI 模型生成结果。

## 当前不包含

电影/电视剧生产数据、动态数据库、账号同步、严格防剧透、投稿审核后台、精确地理导航、图像 API 实际调用、授权原文或视频播放。

详细设计目标见 [文档索引](docs/README.md)。这些是继续迭代的设计基线，不应误读为已经全部实现。

## 开发与素材安全

不要提交 API 密钥。仓库忽略 `.env*`（示例文件除外）。图像服务的接入步骤见 [接入指南](docs/图像生成服务接入指南.md)，当前应用无需 API Key 即可运行。
